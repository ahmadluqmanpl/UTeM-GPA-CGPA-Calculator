# Unofficial UTeM GPA/CGPA Calculator v1.1.2

Quality-of-life improvements and cross-platform UI unification release. This release brings full semester-card feature parity across Windows, Android, and the Web, introducing collapsible semesters, cumulative CGPA tracking, and cleaner data entry.

### ✨ Highlights
* **Collapsible Semesters.** Keep your academic dashboard clean by collapsing and expanding individual semester cards, a feature now fully synchronized across all platforms.
* **Cumulative CGPA Tracking.** Instantly view your overall academic progress with a new, dedicated CGPA badge displayed directly alongside the GPA on each semester card.

### 🎨 UI & UX Improvements
* **Auto-Uppercase Subjects.** Subject codes and names are now automatically formatted to uppercase as you type, keeping your saved records and generated reports looking official and consistent.
* **Balanced Header Layout.** The new collapse/expand toggle button is neatly positioned on the far left of the semester title, matching the Android app's layout for a balanced, native-feeling UI.

### 🔧 Maintenance & Repository Hygiene
* **Cross-Platform Synchronization.** Executed a complete sync of shared UI components to guarantee 100% feature parity across the Windows installer, Android APK, and Cloudflare Worker.
* **Documentation Sync.** Updated the repository task log and deployment guides to reflect the finalized UI alignment and current versioning.
